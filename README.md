# CMWS faithful reconstruction v2

This is a static, Vercel-ready reconstruction designed for easy quarterly maintenance.

## Routine updates
- Add a cask/bottling: edit `data/casks.json` only.
- Add a member club: edit `data/clubs.json` only.
- General principles/text data: `data/site.json`.

The HTML and layout do not need to change for normal additions.

## Pages
- `index.html` — Home
- `about.html` — About CMWS + Member Clubs
- `bottlings.html` — chronological cask/bottling history
- `contact.html` — Contact

## Reconstruction note
The former public CMWS site was not reachable during reconstruction. Historical cask content in this package is limited to material that could be independently recovered or verified. The exact historical member-club list could not be reliably reconstructed from public sources, so only a confirmed founding participant is pre-populated pending CMWS review.
